Full-Time AI Job Scout

This Sheet is the dashboard and database. Apps Script runs the search, dedupes results, and emails only new opportunities.

Use Script Properties for secrets. Do not put API keys in Sheet cells.
  1. Open Apps Script editor from Extensions -> Apps Script.
  2. Go to Project Settings -> Script Properties.
  3. Add TAVILY_API_KEY, GEMINI_API_KEY, and RECIPIENT_EMAIL.
  4. Run setupDashboard once and authorize requested scopes.
  5. Run sendTestEmail.
  6. Run runSearchNow once manually.
  7. Use Job Scout -> Install Daily Trigger.
